# Pet Insurance by State, 2025 — Wagopedia dataset

This repository contains the dataset behind the Wagopedia study "Pet Insurance by State, 2025".

## Data file

- `pet-insurance-by-state-2025.csv` — state-level pet insurance data for 2025.

## Source

- NAPHIA 2026 State of the Industry Highlights, Section 5 (CY2025)

## Study page

- https://wagopedia.com/research/pet-insurance-by-state/

## Open Science Framework

- DOI: https://doi.org/10.17605/OSF.IO/FXWN3

## Notes

- The premium intensity index is a Wagopedia calculation (GWP share ÷ pets share, US = 1.00).
